# 🌐 DummyJSON Dashboard

A responsive multi-page dashboard website built using HTML, CSS, and JavaScript. The project fetches data dynamically from the DummyJSON API and displays Users, Products, Carts, and Quotes.

## ✨ Features

- Responsive Multi-Page Website
- Sticky Navbar
- Hero Section
- Users Dashboard
- Products Dashboard
- Carts Dashboard
- Quotes Dashboard
- Search Functionality
- Filter Functionality
- Sorting
- Pagination
- Loading Spinner
- Error Handling
- Mobile Responsive Design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- DummyJSON API
- Git & GitHub
- Netlify
